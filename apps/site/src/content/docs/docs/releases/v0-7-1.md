Released July 29, 2026. Version 0.7.1 is a reliability release for the journeys surrounding the workspace: getting in, returning offline, starting research, handling concurrent edits honestly, and installing the optional companion from npm.

[Open Dusori](https://udhawan97.github.io/Dusori/app/) · [View the GitHub release](https://github.com/udhawan97/Dusori/releases/tag/v0.7.1)

## Start where the work is

The first run now puts both workspace choices in the opening desktop view instead of below a tall introduction. After naming a topic, Research shows the objective and provider permissions in its first screen. The topic field starts empty, so pressing Enter can no longer create the example topic by accident.

Long topic names keep their icon intact, connectivity status follows the browser as it changes, and the disabled research scan explains which provider permission it needs. Status messages no longer sit invisibly over nearby controls.

## Return offline to the same place

Dusori stores the open topic and view in the URL. The installed app now recognizes that route even when its query string changes and uses the cached application shell at the path where the app is actually deployed. Reopening after real use no longer falls through to the browser's offline error page.

## Research that survives the hosted boundary

OpenAlex and npm discovery now work from the hosted app. Each provider declares the exact host it contacts, and the deployed content-security policy permits those hosts without widening access to arbitrary pages.

If concurrent workspace changes exhaust Dusori's bounded retry path, research history, dismissed results, and imported sources now retain the specific retry-exhausted explanation. The useful recovery guidance is no longer flattened into a generic conflict.

## A verified npm companion

Publishing a GitHub release now starts the companion publish workflow against that version tag. The workflow confirms the tag, package manifest, and runtime version agree; runs formatting, lint, types, unit tests, builds, and the packed-tarball smoke test; then publishes [`@udhawan97/dusori`](https://www.npmjs.com/package/@udhawan97/dusori) with npm provenance.

The mobile navigation drawer also takes keyboard focus, contains Tab while it covers the workspace, and returns focus to the menu button when it closes.
