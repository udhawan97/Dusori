Released August 1, 2026. Version 0.9.0 closes the gap between two things Dusori could already do separately: read a PDF on your device, and turn a certification outline into a topic roadmap. Until now the two never met, so the exact PDF the curriculum importer was written for had to be opened in another reader and pasted in by hand.

[Open Dusori](https://udhawan97.github.io/Dusori/app/) · [View the GitHub release](https://github.com/udhawan97/Dusori/releases/tag/v0.9.0)

## Import an exam guide from the PDF itself

**Curriculum** gains an **Exam guide PDF** field. Choose an AWS Certification exam guide and Dusori reads its text on your device, fills the outline box, and takes the source title from the filename. From there nothing is new: you trim the cover page or the in-scope-services appendix, press **Preview roadmap**, check the objectives, and apply. The roadmap is still written under an expected hash, the outline is still saved to `Sources/`, and an outside edit still becomes a proposal you review as a diff.

The file never leaves your device. A scanned PDF with no text layer still says exactly that instead of importing an empty outline — Dusori ships no OCR.

## Why the line breaks mattered

The reason this took a change rather than a wire-up is worth stating plainly. Dusori's PDF reader used to collapse every run of whitespace on a page, which turned a page into a single line. That is harmless for a prose source and fatal for an outline: every curriculum adapter recognizes its structure at the _start of a line_, so `Domain 1:` and `Task Statement 1.1:` simply stopped existing.

Extraction now keeps the document's own line breaks. The AWS adapter's existing handling — bullet glyphs, a task statement wrapped mid-sentence, the summary table that repeats each domain — was already written for text copied out of a PDF viewer. It only ever needed lines.

PDF sources you add through **Sources** are read by the same extractor, so they now keep their line breaks too. Markdown joins single newlines when it renders, so a stored source reads as it did while staying closer to its page.

## What a non-AWS PDF does

A PDF of any other shape reports that no format matched and names every outline Dusori does support. Its extracted text stays in the outline box, so you can edit it into Markdown headings and preview again rather than starting over.

Microsoft Learn study guides and structured Markdown syllabi still expect pasted text: both recognize themselves by Markdown headings, which extracted PDF text does not carry.

## Unchanged

OCR for scanned documents, a PDF-native outline adapter that guesses at bullet glyphs and heading case, closed-app or unattended work, accounts, sync, and telemetry all remain unbuilt.
