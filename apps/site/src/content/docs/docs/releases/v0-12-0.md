Dusori v0.12.0 reorganizes the product around a learner’s daily loop: **Continue → Read → Annotate → explicitly Mark learned or review → Map/Outline**.

:::caution[Superseded by v0.15.0]
Every v0.12.0 or v0.12.1 desktop build needs one manual v0.15.0 install. Both affected versions open to a launch-time 404, so Settings is inaccessible. The Intel v0.12.0 Mac build also cannot safely select the Apple silicon updater feed. Your workspace is stored separately from the app bundle and remains in place; normal in-app updates work from v0.12.2 onward.
:::

## Learning Studio

- Four predictable destinations replace the tool-shaped navigation: **Learn**, **Sources**, **Map**, and **Settings**.
- Learn opens with one file-derived next step and keeps research, the learning path, reviews, and evidence as contextual topic tools.
- Sources is an obvious saved-evidence shelf with a manifest-derived count.
- Search candidates distinguish **Preview**, **Save source**, and **Save & read**; previewing does not mutate the workspace.
- Saved source text opens in a focused Reading room.
- A topic-local question field searches the learner’s files and opens the supporting artifact without remote AI or automatic chat history.
- Map pairs the explorable galaxy with a linear Outline of the same artifacts.

## Honest progress and compatibility

- Roadmap objectives change only through an explicit checkbox action; topic status remains a separate state.
- Workspace parsers accept compatible unknown fields, and supported edits preserve them instead of silently downgrading newer data.
- Import preflight is bounded before writes begin.
- Provider availability and individual run outcomes remain separate, so a service outage cannot look like an empty result.

## Desktop apps and updates

- New Tauri desktop builds target macOS Apple silicon, macOS Intel, and Windows x64.
- Each app bundles a target-native Node.js 24 runtime and loopback companion sidecar.
- Settings included controls intended to check, download, verify, and explicitly install an update, but v0.12.0's launch-time 404 made that UI inaccessible.
- Automatic update opt-in covers checking and downloading only. It never installs or restarts on its own.
- Installation is blocked while work is unsaved.
- The release workflow cryptographically verifies all three signed updater targets, produces `latest.json` and `SHA256SUMS.txt`, and stages an exact-asset draft from the matching version tag. A maintainer publishes only after downloading and independently checking that draft.

The v0.12.0 OS installers are not Apple-notarized or Microsoft code-signed, so Gatekeeper or SmartScreen may warn. The in-app updater uses a separate cryptographic signature. See [Updates and recovery](../../updates/).

## Research boundary correction

YouTube discovery prefers the official Data API v3 through a user-supplied `YOUTUBE_API_KEY`, with an optional self-hosted `INVIDIOUS_URL` fallback. Both save metadata and a reference only. Dusori no longer attempts to harvest captions. Transcript text may be added through Paste or File only when the learner supplied it, owns it, or has permission.

The loopback companion no longer exposes its per-run credential in the opened URL, stdout, or logs. The bundled page uses a restricted same-origin cookie; desktop API-only sessions use an environment-provided token and exact origin.
