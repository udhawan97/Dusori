---
title: v0.11.2 release
description: Evidence-gated research actions, reliable focus and dates, and narrow-screen flow fixes.
---

Dusori v0.11.2 closes the gaps found in two complete user-flow design passes. It adds no new network, storage, or AI boundary; it makes the existing research-first path more reliable for touch, keyboard, and narrow-screen use.

## Evidence before artifacts

**Read saved sources** remains unavailable until a source exists. **Build synthesis** and **Create learning page** remain unavailable until reading has produced at least one quoted passage. Each handler repeats the check immediately before it writes, so a stale or forcibly enabled control still cannot create a zero-evidence artifact.

The source count and quoted-passage count refresh after every accepted source and read. Overlapping source-library refreshes now apply only the latest result, while repeated read requests enter their busy state before the first asynchronous check.

Synthesis and learning-page requests also enter their busy state and clear prior feedback before asynchronously rechecking the evidence. A new request therefore cannot look complete because an earlier success message was still visible, and a fast repeat cannot skip its optional AI work.

## A complete keyboard handoff

After **Add to sources** succeeds, keyboard focus moves to the persistent confirmation that names the source that was saved. Closing the preview without accepting still returns focus to the preview control. That makes both branches of the modal flow explicit to keyboard and assistive-technology users.

## Narrow screens keep their actions

Research controls now shrink with their container instead of widening a 320px page. The first-run introduction also becomes more compact on the narrowest supported screens, keeping the 44px workspace action entirely visible at 320×568.

## One date across devices

Dated update paths, recap bounds, Insights activity series, and their rendered labels all use the same UTC calendar key. The label remains localized, but another device timezone can no longer move the activity to the previous or next day. Review scheduling remains intentionally local to the learner.

## Unchanged boundaries

Nothing runs while Dusori is closed. Reading saved sources is local and deterministic. Optional AI remains separately consent-gated and model-named, reading arbitrary web pages still requires the loopback companion, and every workspace artifact remains in the existing portable file contract.
