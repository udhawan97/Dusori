Released 2026-08-11.

v0.12.4 keeps the v0.12.3 Research Desk and its workspace format, then reduces the number of places
that can disagree about how a run, provider, Today snapshot, or navigation change works. This is a
reliability release: the visible Ask → Search → Save → Read → Brief flow remains the same.

## One complete research run

One tested operation now owns the whole transaction after consent:

1. search the providers allowed for this exact question;
2. preserve `found`, `empty`, and `failed` outcomes;
3. rank and save a varied shortlist of up to eight results;
4. keep each capture failure as a reference with a failure trail;
5. read only locally available text into quotable passages; and
6. write the evidence-backed brief or preserve an edited brief and create a proposal.

Provider failures remain partial failures. An unavailable optional model falls back to deterministic
synthesis. A URL-only result still cannot support a claim.

## One provider catalog

The 13 research providers now share one registration source for availability, consent label and
scope, query audience, evidence lens, capture policy, and browser origin. The hosted and desktop
content-security policies are tested against those origins, so adding a browser provider cannot
quietly ship behind a policy that blocks it.

The catalog does not turn providers into plugins. Each provider remains an explicit adapter, and
the interface still asks before any query leaves the device. Optional AI keeps its own separate
consent.

## Consistent Today and navigation

- Today receives one complete, read-only snapshot with one clock. It does not write progress,
  repair files, or infer mastery.
- Workspace view changes share one set of topic, document, URL, Back/Forward, and new-topic rules.
  Browser history, local document reads, scroll, and focus remain explicit UI effects.

## Dependency and security refresh

The release updates PDF.js, Vite, Playwright, `tsx`, and the Astro ESLint plugin. It also takes the
current Fastify, Mermaid, Sharp, URI, glob-expansion, YAML, and Nano ID security patches. One
regenerated lockfile replaces the five independently generated dependency-update lockfiles. The
production audit has no high or moderate findings.

## Desktop support and trust

- macOS 12 or newer on Apple silicon only
- Windows x64
- Browser/PWA and Node.js 24 companion
- Signed GitHub updater artifacts with separate check, download, install, and relaunch actions

The Mac and Windows installers are open-source builds but are not Apple-notarized or Microsoft
code-signed. Gatekeeper or SmartScreen may warn on first launch; compare the installer with
`SHA256SUMS.txt` from the release. The updater signature is a separate trust mechanism.

:::caution[One-time repair for v0.12.0 and v0.12.1]
Those two desktop versions open to a launch-time 404, so Settings is inaccessible.
Install v0.12.4 manually once. The workspace is stored separately and remains in place.
Normal in-app updates work from v0.12.2 onward.
:::
