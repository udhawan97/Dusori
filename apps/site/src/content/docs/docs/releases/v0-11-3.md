Dusori v0.11.3 completes the [v0.11.2 user-flow hardening](../v0-11-2/) with one release-gate correction.

## The fallback message now means the file is ready

When optional synthesis AI was unavailable, Dusori immediately showed that it would use the deterministic synthesis. On a slower device, that notice could appear while the previous model-written `Synthesis.md` was still on disk. A user or automated reader responding to the notice could briefly reopen the stale version.

Dusori now holds the fallback notice until the deterministic output has finished writing. Without an edit conflict, `Synthesis.md` already contains the quoted, source-cited fallback when the message appears. If the learner edited that file outside Dusori, their version remains active and the deterministic fallback is already waiting as a conflict-safe proposal in **Needs attention**.

The failed release-gate flow passed ten consecutive repetitions under five parallel browser workers after the correction. A separate regression preserves an externally edited synthesis and verifies the deterministic proposal, followed by the complete Node 24 and browser suites.

## Unchanged boundaries

The fallback remains local and deterministic. No new network, storage, or AI permission is introduced; the earlier narrow-screen, evidence-gating, focus, UTC-date, and overlapping-request corrections remain unchanged.
