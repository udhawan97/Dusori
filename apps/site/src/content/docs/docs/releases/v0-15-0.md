Dusori v0.15.0 makes the research trail portable and inspectable without turning it into a cloud
activity feed. Questions now have stable local identities, saved actions form a bounded typed
trail, research packets carry exact provenance, and citation details can be corrected locally.

## Move from a question to evidence more directly

Research now follows one question-first flow from plan through source review, evidence, and brief.
Saved sources, notes, and threads can be organized with normalized tags, while explicit
learner-authored `supports`, `challenges`, `updates`, `background-for`, and `follow-up-to` relations
connect artifacts without moving or copying them.

Quotes now carry a versioned local locator with normalized fingerprints, bounded context,
Unicode-code-point positions, and retained PDF page identity. If the stored text changed or a match
is ambiguous, Dusori keeps the original quote and fails closed. Map explains why each edge exists
and can jump directly to the stored source, annotation, research event, or artifact behind it.

## Keep a durable question trail

Each new question receives a stable topic-local thread identity. Explicit follow-ups link to their
parent, while older research remains readable without invented IDs. The activity view distinguishes
provider lookup receipts from saved sources, read evidence, annotations, answers, and exports.

The trail is bounded rather than permanent. Compaction preserves the minimum identity needed for
live links, and deleting or redacting a thread warns that previously exported files are independent
copies.

## Follow research locally

Follow or unfollow a question explicitly. The workspace-wide Updates inbox is derived from saved
thread activity and has no cloud delivery, notification, unread state, provider request, or refresh
side effect.

## Export an evidence-linked packet

Markdown, standalone HTML, and user-initiated Print/PDF packets are rendered from the same stored
research boundary. Each export includes a JSON provenance manifest with local content hashes,
omitted-path status, evidence counts, and an explicit `roundTrip: false` marker. The HTML packet is
network-inert.

## Correct citation details without a lookup

On a saved source, choose **Edit citation** to correct a DOI, ISBN, arXiv, PMID/PMCID, OpenAlex, or
Open Library identifier and optionally name its journal or collection. Dusori validates and
normalizes those values locally, preserves earlier provenance, and records a bounded manual
correction receipt.

This action does not contact a resolver, change the source text, make a reference count as readable
evidence, or refresh the brief. Resolver calls remain unbuilt and would require separate consent.

## Privacy and compatibility

- Workspace schema remains version 1 with additive, bounded fields.
- Citation normalization, thread following, the Updates inbox, and packet rendering make no network
  request.
- Import validation and exact ZIP round-trip coverage include the additive thread and citation
  records.
- Browser PWA, Node companion, macOS Apple silicon app, and Windows x64 app share these behaviors.
- macOS and Windows installers are not Apple-notarized or Microsoft Authenticode-signed. Verify the
  official checksums; updater signatures are a separate trust mechanism.
- Astro, Starlight, the Anthropic SDK, emnapi runtime, and tsx are refreshed to their reviewed
  maintenance versions.
