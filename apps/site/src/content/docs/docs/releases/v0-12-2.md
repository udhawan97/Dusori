Dusori v0.12.2 corrects the desktop artwork shipped in v0.12.1. The app icon now comes from the same identity shown at the top of the README: an open ensō around marigold rangoli geometry, crossed by a vermilion katana.

:::note[Superseded by v0.12.3]
v0.12.3 keeps these desktop repairs and adds the current Research Desk and learning workflow. v0.12.2 can use the in-app updater normally.
:::

## Corrected

- macOS Finder, Applications, Dock, and running-app artwork use the canonical README-derived icon.
- Windows uses the matching regenerated ICO.
- The Apple-silicon DMG uses the same mark and warm ink, paper, marigold, and vermilion palette.
- A release-contract test prevents the desktop icon source from drifting away from the canonical public app-icon asset again.
- The desktop window now opens at the app's base route instead of treating `index.html` as a Svelte route, fixing the launch-time **404 Not Found** screen.

This patch does not change workspace files, research behavior, progress, or the updater trust boundary. The macOS release remains Apple-silicon-only; Windows x64 remains available.

## Updating

Every v0.12.0 or v0.12.1 desktop build needs one manual v0.12.3 install. Both affected versions open to a launch-time 404, so Settings is inaccessible. The Intel v0.12.0 Mac build also cannot safely select the Apple silicon updater feed. Workspace data is separate from the app bundle, and normal in-app updates resume from v0.12.2 onward.

The OS installers are not Apple-notarized or Microsoft code-signed. Verify the downloaded installer against `SHA256SUMS.txt`; in-app update artifacts use a separate cryptographic updater signature.
