Dusori v0.12.1 repairs the Mac distribution that shipped with v0.12.0. The macOS app is now Apple silicon only; Windows x64 remains supported.

## Mac packaging

- The macOS executable and bundled Node.js 24 companion runtime are built for `arm64`.
- Intel Mac builds and the `darwin-x86_64` updater entry are removed.
- Finder, Applications, and the Dock use the supplied nine-diamond icon.
- The disk image uses a branded drag-to-Applications layout instead of the unstyled default window.
- Release verification rejects a Mac build unless it is the Apple silicon target.

## One-time upgrade from v0.12.0

The v0.12.0 Mac app identifies itself as Intel even when Rosetta runs it on an M-series Mac. It therefore cannot safely choose this release's Apple silicon updater entry. Install the v0.12.1 Apple silicon DMG manually once. The workspace is stored separately from the app bundle and remains in place; native in-app updates resume after this repair.

## Updates and safety

- `latest.json` contains only Apple silicon macOS and Windows x64 updater entries.
- Check, download, install, and restart remain separate actions.
- The app still refuses to install an update while work is unsaved.
- The OS installers are not Apple-notarized or Microsoft code-signed. Gatekeeper or SmartScreen may warn even though in-app update artifacts use a separate Dusori signature.
