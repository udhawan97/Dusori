Released July 28, 2026. Version 0.6.0 made the constellation something you could move through — zoom, pan, and tune. Version 0.7.0 makes it something you can arrange. Placement, filtering, and color are all view settings that live in your browser and write nothing into your workspace.

[Open Dusori](https://udhawan97.github.io/Dusori/app/) · [View the GitHub release](https://github.com/udhawan97/Dusori/releases/tag/v0.7.0)

## Placement that stays put

Drag any artifact and it stays where you drop it. Its neighbors resettle around the new position instead of snapping back, so you can pull a cluster apart to read it and have it stay readable.

A focused artifact moves from the keyboard as well: arrow keys nudge it, and Shift with an arrow key takes a larger step. Placement never depends on a pointer. **Release pins** hands every artifact you have placed back to the layout, and stays disabled until something is actually pinned.

## Filters from your own structure

Dusori already knows what each file is, so the graph filters on that rather than a query language:

- **Show on the graph** chips toggle Notes, Sources, Updates, Documents, and Meta — roadmaps and learning preferences.
- **Hide orphans** drops artifacts carrying no wikilinks.
- The workspace center and topic centers always stay visible, so the constellation never loses its shape.
- The panel counts what survived: "12 of 40".

## Color by kind or topic

**Color by** switches artifact dots between **Kind**, the default, and **Topic**, which gives each topic a hue with a legend beside the control. Hues are derived from the topic name, so the same workspace draws the same colors on every machine — nothing is stored and nothing is random.

## The finder now follows the graph

The **Artifact finder** beside the stage used to search the whole workspace independently of what the constellation was showing, which meant the list could name artifacts the graph had hidden. It now searches within whatever the graph is currently drawing.

The two filters work in layers: **Show on the graph** decides what exists on screen, and the finder helps you locate something inside that. Hiding Sources on the stage removes them from the list too.

## What this release does not do

Zoom, pan, sliders, filters, and the color choice are view settings held in this browser only. Placement lasts for the session. None of it writes coordinates, layout files, or view state into your workspace — opening the same folder in Obsidian stays clean, and export still carries everything needed to redraw the graph elsewhere.

Reduced-motion users get the settled layout immediately, with no spatial animation. No graph database appears, nothing is sent anywhere, and the graph still works offline once the app has loaded.
