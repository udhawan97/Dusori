title: Dusori v0.15.1

Dusori 0.15.1 is a small reliability release focused on CI/CD correctness and release integrity.

## Preview-first machine-file recovery

- Continued delivery of the preview-first recovery workflow for invalid workspace, topic, source, and research
  files.
- Improved recovery visibility so learners can see the exact proposed replacement and choose recovery only when
  intended.
- Preserved manual recovery workflows when external edits invalidate a reviewed plan.

## CI/CD reliability

- Fixed the verification pipeline formatting mismatch that was failing `prettier --check` in CI on the main release
  track.
- Added release metadata updates (changelog + package versions) to keep tag-based release workflows in-sync.
