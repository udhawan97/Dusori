Three additions that finish the research-first loop started in [v0.10.0](../v0-10-0/): the generated learning page becomes readable in place, a topic can keep itself current, and the synthesis gains optional written prose over its own quotations.

## Open the learning page inside Dusori

The generated page was a file you had to leave Dusori to read. **Open learning page** now renders it in place.

It runs in a sandbox that permits the page's own scripts but denies it the app's origin, so its check-yourself prompts still work while the page cannot reach your workspace, its storage, or its cookies.

The stored file stays theme-neutral and follows your own system preference when you open it directly — it is still an ordinary portable file. Only the copy shown inside Dusori is matched to the app's current theme.

## Keep this topic fresh

A per-topic setting gives Dusori standing permission to re-scan a topic when you open it and it has gone seven days without a scan. It uses only the providers you already allowed, and it reports what it found — including when it found nothing new.

The boundaries are deliberate:

- Never on a first visit. A topic that has never been scanned has nothing to refresh, so the first run stays your choice.
- At most once per topic per session, however often you navigate back to it.
- Never while Dusori is closed. There is still no background work, no daemon, and no schedule.

The setting lives in the topic's `research.json` and travels with your workspace. Its control stays disabled until the file holds the answer, so it can never look saved while the write is still in flight.

## AI-written synthesis overview

With the companion running and an AI provider configured, **Build synthesis** can add two or three paragraphs of overview prose above the quotations.

The prose is written over the passages your workspace already quotes — nothing else is sent — and it is labeled with the model that wrote it. Everything that carries evidential weight stays deterministic: the quotations themselves, their citations, the thin-evidence marking, the timeline, and the evidence table. A model that is unavailable or unusable writes the document without commentary and says so.

This keeps the standing rule that has applied to ranking and briefs since v0.5.0: AI is advisory, model-named, consent-gated, and always has a deterministic fallback.

## Limitations

Unchanged from v0.10.0. Reading arbitrary web pages still needs the local companion; without it the providers that reach real text are Wikipedia, OpenAlex, GitHub, Stack Exchange, Hacker News, and npm. Dusori still performs no closed-app work of any kind.
