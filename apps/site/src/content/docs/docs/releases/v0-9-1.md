Released August 2, 2026. Version 0.9.1 is a release-integrity patch: the app behavior from v0.9.0 is unchanged, while the npm package and every public install path now point to one verifiable release.

[Open Dusori](https://udhawan97.github.io/Dusori/app/) · [View the GitHub release](https://github.com/udhawan97/Dusori/releases/tag/v0.9.1) · [View the npm package](https://www.npmjs.com/package/@udhawan97/dusori/v/0.9.1)

## One current local command

With Node.js 24 LTS installed, `npx @udhawan97/dusori@latest` downloads and opens the current Dusori companion without a global install. Folder access stays off unless you explicitly add `--root "/path/to/Dusori"` for that session.

The browser app remains the no-terminal path. The v0.9.1 source ZIP and repository clone remain available for people who want the full source workflow.

## Provenance must match the package

The npm workflow now checks that the release tag, checked-out source, and GitHub Actions workflow revision resolve to the same commit before it builds or publishes. A manual recovery launched from a different branch revision stops instead of producing provenance for code other than the packaged tag.

## Product behavior

No workspace, storage, network-consent, or learning behavior changed in this patch. The on-device AWS exam-guide PDF import introduced in v0.9.0 remains the newest product capability.
