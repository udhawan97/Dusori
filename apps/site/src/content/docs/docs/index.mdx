Dusori is a local-first learning workspace. The current build includes durable browser storage, an optional real-folder path on supported Chromium browsers, validated rollback-safe ZIP replacement, conflict-safe Markdown note authoring, local full-text search, backlinks and workspace health, offline use, a local source library, preview-first curriculum import, automatic consent-gated research across seven keyless browser providers, an optional companion for arXiv, Reddit, configured web search, confirmed readable-page extraction, and optional AI assistance, a deterministic review queue and recap with optional spaced review, source-grounded active-recall sessions built from your own approved sources, tags read from your own Markdown, on-device PDF text extraction, editable per-topic learning preferences, a portable knowledge graph, and local file-derived Insights.

The hosted app does **not** fetch arbitrary pages. The companion fetches only a URL source you explicitly confirm. Local workspace search never sends a query away. Discovered results remain suggestions until you approve them. A PDF is read on your device and never uploaded; Dusori performs no unattended work. Optional AI is consent-gated, model-named, advisory, and always has a deterministic fallback. Review scheduling is optional and exists only for topics you explicitly mark reviewed.
