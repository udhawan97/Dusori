Dusori is a local-first, research-first learning workspace. Name a topic and it becomes a research mission: consent-gated search across seven keyless browser providers, a durable trail recording what each provider returned or failed to return, verbatim quoted passages read from the sources you approve, a synthesis where every line cites the file it came from, and an optional self-contained interactive learning page you can read in place or open without Dusori. A topic can be armed to re-scan itself when you open Dusori a week later.

The rest of the build: durable browser storage, an optional real-folder path on supported Chromium browsers, validated rollback-safe ZIP replacement, conflict-safe Markdown note authoring with a durable proposal lifecycle, local full-text search, backlinks and workspace health, offline use, a local source library, preview-first curriculum import from pasted text or an AWS exam guide PDF, an optional companion adding arXiv, Reddit, configured web search, YouTube through your own Invidious instance, confirmed readable-page extraction, and optional AI assistance, evidence-driven Continue learning and Needs attention lanes with optional spaced review, source-grounded active-recall sessions built from your own approved sources, tags read from your own Markdown, on-device PDF text extraction, editable per-topic learning preferences, a portable knowledge graph, and local file-derived Insights.

The hosted app does **not** fetch arbitrary pages. The companion fetches only a URL source you explicitly confirm. Local workspace search never sends a query away. Discovered results remain suggestions until you approve them. A PDF is read on your device and never uploaded. Nothing runs while Dusori is closed: the one action Dusori takes without asking each time is re-scanning a topic you explicitly armed, when you open it and a week has passed, using only providers you already allowed. Optional AI is consent-gated, model-named, advisory, and always has a deterministic fallback. Review scheduling is optional and exists only for topics you explicitly mark reviewed.
