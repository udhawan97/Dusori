Dusori is a local-first, research-first learning workspace. Name a topic and it becomes a research mission. Dusori searches the providers you allow — seven of them need no API key and no companion — and keeps a durable trail of what each one returned or failed to return. The sources you approve are read into verbatim quoted passages, and those passages build a synthesis in which every quoted passage cites its source. A well-supported topic can become a self-contained interactive learning page you read in place or open without Dusori.

Around that sits the rest of the workspace: durable browser storage, an optional real folder on supported Chromium browsers, rollback-safe ZIP replacement, conflict-safe Markdown notes, full-text search, backlinks, a portable knowledge graph, and file-derived Insights. Curriculum import turns pasted text or an AWS exam-guide PDF into a roadmap you review first. Review sessions build recall prompts from your own approved sources.

The hosted app does **not** fetch arbitrary pages. The companion fetches only a URL source you explicitly confirm, and it is what adds arXiv, Reddit through your own Reddit app, YouTube through your own Invidious instance, one configured web-search provider, and optional AI. Local workspace search never sends a query away. Discovered results remain suggestions until you approve them. A PDF is read on your device and never uploaded. Nothing runs while Dusori is closed, and the only work Dusori starts without asking each time is re-scanning a topic you explicitly armed, when you open that topic and a week has passed, using only providers you already allowed. Optional AI is consent-gated, model-named, advisory, and always has a deterministic fallback.
